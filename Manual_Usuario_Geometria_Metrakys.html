1. Objetivo y alcance

Este manual explica cómo utilizar el software interno de Geometría de máquinas de Metrakys Metrology para importar datos de medición, configurar evaluaciones, revisar resultados, generar tablas de compensación y preparar informes.

La herramienta trabaja a partir de datos copiados en formato Quick Report desde el software metrológico. El usuario define las evaluaciones y los parámetros de análisis; la aplicación procesa los datos y presenta resultados, gráficos y tablas.

Importante: el software es una herramienta de cálculo y presentación. No sustituye la preparación del ensayo, la alineación ni las decisiones técnicas que deben realizarse en el software metrológico y conforme al procedimiento aplicable.

La interfaz incluye selector de idioma (español, inglés y portugués). Los nombres de algunos controles pueden variar según el idioma seleccionado; este manual utiliza principalmente los nombres visibles en español o los términos técnicos que aparecen en la aplicación.

2. Flujo general de trabajo

Preparar los Quick Reports

Realizar y revisar las mediciones en el software metrológico. Copiar el Quick Report correspondiente a cada ensayo.

Introducir los datos del proyecto

Identificar proyecto, máquina, número de serie, fecha, operador y equipo utilizado.

Crear y configurar las evaluaciones

Añadir una tarjeta por cada combinación de ensayo, eje y conjunto de datos que se desea analizar.

Calcular y revisar

Ejecutar las evaluaciones y revisar estados, valores, gráficos, tablas y posibles avisos.

Generar complementos

Cuando proceda, crear tablas de compensación, evaluaciones de ESQUADRAJE y análisis complementarios.

Preparar el informe

Seleccionar las secciones que deben incluirse y utilizar la función de impresión del navegador para imprimir o guardar en PDF.

Recomendación: trabajar de forma ordenada y calcular las evaluaciones antes de generar compensaciones o preparar el informe final.

3. Importar Quick Report

Cada tarjeta de evaluación dispone de un área de texto independiente para su Quick Report. Los datos pegados en una tarjeta se utilizan únicamente en esa evaluación.

Copiar el Quick Report

Desde el software metrológico, copiar el bloque de puntos que se desea evaluar, incluyendo los encabezados de grupo, nombre de punto y coordenadas.

Pegar en la tarjeta correcta

Pegar el contenido en el campo «Quick Report de este ensayo» de la evaluación correspondiente. No mezclar ensayos distintos en una misma tarjeta.

Leer el Quick Report

Hacer clic en «Leer Quick Report de esta tarjeta». La aplicación interpreta los grupos y las columnas reconocidas.

Seleccionar el grupo

Si el bloque contiene varios grupos compatibles, seleccionar el grupo que corresponde al ensayo. La evaluación utiliza un único grupo por tarjeta.

Tarjeta de evaluación · Ejemplo visualQuick Report
Quick Report de este ensayoPoint Group · Nombre del grupo
Point Name · X · Y · Z
(mm) · (mm) · (mm)
POSXCC0 · 0 · 0 · 0
Leer Quick Report de esta tarjeta
Comprobación: después de leer los datos, revisar el mensaje de estado de la tarjeta y confirmar que el grupo seleccionado contiene los puntos y las coordenadas esperadas. Si el grupo no es compatible con el eje elegido, la evaluación no podrá calcularse correctamente.

La aplicación reconoce grupos lineales con coordenadas como X, Y, Z, V1 o V2 y grupos angulares que incluyen R y Theta, según la estructura del Quick Report.

5. Configurar evaluaciones

En la sección «Configuración», añadir una tarjeta por cada evaluación que se quiera realizar. La aplicación inicia con tarjetas de evaluación disponibles y permite añadir, duplicar o eliminar tarjetas.

5.1 Tipo de ensayo

  • Posicionamiento: seleccionar para evaluar los datos de posicionamiento del eje.
  • Repetitividad: seleccionar para evaluar la repetitividad conforme a los recorridos y ciclos definidos.
  • Retitude: seleccionar para evaluar la retitude. Esta opción no está disponible para los ejes angulares.

5.2 Eje y tipo de datos

Seleccionar el eje que corresponde al ensayo: X, Y, Z, V1, V2, A, B o C. La selección del eje determina qué tipo de grupo y qué columnas de datos se esperan.

Para V1 y V2 aparece un campo adicional para definir la coordenada medida. Puede utilizarse la detección automática o seleccionarse X, Y o Z cuando sea necesario identificar explícitamente la coordenada.

Para determinados ensayos angulares aparece la configuración específica de columna angular, unidad angular y factor de importación. Estos campos solo deben modificarse conociendo el formato y las unidades de origen del Quick Report.

5.3 Parámetros nominales

ParámetroOrientación de uso
Punto inicialPrimera posición nominal del recorrido. En evaluaciones angulares, el campo se interpreta en la unidad angular configurada.
Punto finalÚltima posición nominal del recorrido.
IntervaloSeparación nominal entre posiciones. Debe ser mayor que cero.
N.º de ciclosNúmero entero de ciclos, igual o superior a uno.
Modo de mediciónIndicar si el ensayo se ha realizado en modo bidireccional o unidireccional.

5.4 Estado / compensación

Seleccionar la opción que identifica el estado de compensación aplicable al ensayo: SC, CC, CC2 o CC3. La selección debe corresponder a las condiciones reales de medición y al procedimiento utilizado.

5.5 Tolerancia

Definir el valor de tolerancia y seleccionar una unidad compatible con la magnitud evaluada. Para ejes lineales se ofrecen unidades lineales; para ejes angulares se ofrecen unidades angulares. No se realiza una conversión entre longitud y ángulo.

En evaluaciones lineales se puede seleccionar la aplicación de tolerancia:

  • Fija: mantiene la regla fija configurada.
  • Proporcional a la distancia desde el origen: la tolerancia varía con la distancia total desde el origen.
  • Proporcional por intervalo: aplica la proporción a cada intervalo de medición, sin acumular los intervalos anteriores.

Cuando se elige una aplicación proporcional, completar también el largo de referencia y su unidad.

5.6 Duplicar o eliminar una evaluación

El botón «Duplicar» crea otra tarjeta copiando la configuración y el texto del Quick Report de la tarjeta de origen. Revisar todos los campos y el conjunto de datos antes de calcular. «Remover» elimina la tarjeta correspondiente.

No asumir que los valores iniciales de una tarjeta son los valores correctos para cualquier máquina o ensayo. Confirmar siempre eje, recorrido, intervalo, ciclos, tolerancia, unidades y datos importados.

5.7 Calcular evaluaciones

Cuando las tarjetas estén configuradas, pulsar «Calcular evaluaciones». La aplicación valida los datos y muestra los resultados disponibles. Si una tarjeta presenta un error, leer el mensaje de esa tarjeta, corregir la configuración o el Quick Report y volver a calcular.

6. Evaluación de retitude

Al seleccionar el tipo de ensayo «Retitude» en un eje lineal, aparecen campos específicos para configurar las dos componentes de retitude, el conjunto o línea y el tipo de coordenadas.

  • Retitude 1 y Retitude 2: seleccionar dos componentes distintas, disponibles según el eje.
  • Conjunto / línea: identificar la línea o conjunto correspondiente.
  • Tipo de coordenadas: indicar si las coordenadas ya están creadas o si todavía no existe el sistema de coordenadas requerido.

Cuando se selecciona «Sin coordenadas creadas», el software puede presentar un diálogo de diagnóstico para revisar la creación automática del sistema local. El diálogo muestra una comparación de las coordenadas originales y las coordenadas locales propuestas.

Confirmación necesaria: revisar el diagnóstico antes de confirmar la transformación. La aplicación indica si la evaluación utiliza coordenadas originales del Quick Report o coordenadas transformadas automáticamente. No confirmar una transformación sin comprobar que corresponde a la configuración geométrica del ensayo.

Si hay datos disponibles para revisión, el botón «Revisar coordenadas» permite abrir la revisión de coordenadas de retitude.

7. Resultados y filtros

Después de calcular correctamente, aparece la sección «Resultados», con un resumen del proyecto, indicadores generales, gráficos y tablas detalladas.

7.1 Estado de evaluación

Los resultados pueden mostrar los estados PASS y FAIL. Interpretar el estado junto con la tolerancia configurada y los valores presentados; no modificar la tolerancia solo para obtener un estado favorable.

7.2 Filtrar resultados

FiltroFunción
Filtrar evaluaciónMostrar una evaluación concreta o todas.
Filtrar estadoMostrar todos los estados, solo PASS o solo FAIL.
Filtrar punto / posiciónBuscar por valor de posición o por nombre de punto, por ejemplo 500 o POSXCC10.

Las tablas permiten ordenar determinadas columnas haciendo clic en su encabezado y expandir o minimizar la visualización de todos los puntos.

7.3 Exportar resultados

  • Exportar resultados filtrados CSV: descarga un archivo CSV con los datos de las evaluaciones y filas de resultados incluidas en la exportación. El archivo puede abrirse en una hoja de cálculo.
  • Copiar líneas Renishaw filtradas: copia las líneas Renishaw disponibles para utilizarlas en el flujo de trabajo correspondiente.
Antes de exportar, comprobar qué evaluación, estado o posición está seleccionada en los filtros. Para preparar un informe completo, se puede elegir la opción de impresión que ignora los filtros.

8. Tabla de compensación

La sección «Tabla de compensación» genera tablas a partir de los resultados de las evaluaciones calculadas. Por ello, es necesario calcular primero las evaluaciones.

Seleccionar evaluación / eje

Elegir una evaluación válida de la lista. La lista se alimenta de las evaluaciones calculadas correctamente.

Elegir tipo de tabla

Seleccionar «Combinada» o «Separada», cuando las opciones estén disponibles para el tipo de evaluación.

Seleccionar controlador

Elegir SIEMENS o FANUC. Algunas configuraciones fuerzan FANUC automáticamente según el eje o la evaluación.

Definir resolución

Para las tablas lineales, seleccionar la resolución disponible: 0.001 mm o 0.0001 mm. En determinados modos angulares la resolución se define automáticamente y el campo puede ocultarse.

Generar y revisar

Pulsar «Generar tabla de compensación» y revisar el mensaje, el eje, el controlador, el tipo de tabla y todos los valores producidos.

8.1 Combinada y separada

  • Combinada: genera una tabla combinada según el método definido para el controlador y la evaluación.
  • Separada: genera tablas direccionales cuando el método seleccionado lo admite.

8.2 Convención y controlador

La información de la aplicación distingue la convención del controlador. Para SIEMENS, la indicación general es «Absolute · As errors»; para FANUC, «Incremental · As compensations». Los modos angulares específicos presentan sus propias indicaciones.

8.3 Selección para el informe y exportación

Las tablas generadas se pueden seleccionar o desmarcar en «Tablas para incluir en el informe». También existen opciones para copiar la tabla y exportarla a CSV. Si se desea imprimir una tabla, generarla antes y marcarla para incluirla en el informe.

No todas las combinaciones de eje, tipo de evaluación, controlador y sentido de medición son compatibles. La aplicación puede bloquear una combinación o mostrar un mensaje cuando falten recorridos, posiciones coincidentes o puntos de referencia requeridos. No ignorar esos mensajes ni completar los datos con valores inventados.

9. ESQUADRAJE

La sección «ESQUADRAJE» evalúa la desviación del segundo eje de la combinación seleccionada con respecto al primer punto importado.

Añadir ESQUADRAJE

Pulsar «Añadir ESQUADRAJE» para crear una tarjeta de análisis.

Importar el Quick Report

Pegar el Quick Report del ensayo y pulsar «Leer Quick Report».

Seleccionar el tipo

Elegir una de las combinaciones disponibles: ZX, ZY, YX, XY, XZ o YZ.

Configurar tolerancia si aplica

La tolerancia es opcional. Si se utiliza, seleccionar su unidad y el modo de aplicación.

Calcular

Pulsar «Calcular ESQUADRAJE» y revisar el estado, el resumen y la tabla de puntos y desviaciones.

9.1 Aplicación de tolerancia

  • Fija: utiliza la tolerancia definida como valor fijo.
  • Proporcional a la distancia desde el origen: la tolerancia aumenta según la distancia total respecto al origen y requiere longitud de referencia.
  • Proporcional por intervalo: aplica la proporción a cada paso de medición, sin acumular los pasos anteriores; requiere longitud de referencia.
Condición previa: el Quick Report debe estar alineado y el Best Fit debe estar concluido en el software metrológico. Esta herramienta no alinea, no reconstruye la geometría y no modifica las coordenadas originales.

10. Análisis complementarios

Esta sección permite documentar resultados procedentes de otros programas metrológicos. Los datos se incorporan al informe sin que la herramienta vuelva a calcular o transforme los resultados externos.

10.1 Crear un análisis

  1. Pulsar «Añadir análisis».
  2. Introducir un título descriptivo.
  3. Añadir imágenes cuando sea necesario y completar sus leyendas.
  4. Configurar las verificaciones básicas o el análisis de tolerancia, si procede.
  5. Incluir Quick Reports de origen y datos complementarios que deban documentarse.

10.2 Verificaciones básicas

Se pueden activar «Punto máximo» y «Punto mínimo», elegir el Quick Report de origen y seleccionar la columna o parámetro que se desea consultar. La unidad puede indicarse cuando sea necesario.

10.3 Análisis de tolerancia

Activar el análisis y seleccionar el Quick Report de origen, la columna o parámetro, la unidad original de la columna, la unidad de tolerancia y el formato:

  • Bilateral simétrica (±)
  • Límite máximo y mínimo
  • Límite máximo permitido
  • Límite mínimo permitido

La aplicación contempla conversión entre milímetros y micrómetros (1 mm = 1000 µm). Los grados no se convierten en unidades lineales.

10.4 Almacenamiento local y backup

Los análisis complementarios se guardan en el almacenamiento local del navegador. No se trata de un historial central compartido entre usuarios o equipos.

Para transferirlos a otro dispositivo o conservar una copia, utilizar «Exportar backup JSON». Para recuperar una copia anterior, utilizar «Importar backup JSON» y seleccionar el archivo correspondiente.

Las imágenes y los datos complementarios también forman parte de este almacenamiento local. Mantener copias de seguridad cuando sean importantes para el expediente.

11. Preparar e imprimir informe

La sección «Imprimir informe» permite seleccionar un formato predefinido o personalizar las secciones que se incluirán. La salida se prepara para impresión en formato A4 y puede guardarse como PDF desde el diálogo de impresión del navegador.

11.2 Secciones personalizables

  • Datos del proyecto y máquina.
  • Resumen general de resultados.
  • Gráficos.
  • Tablas con todos los puntos.
  • Resultados de ESQUADRAJE.
  • Análisis complementarios.
  • Tabla(s) de compensación.

También existe una opción para imprimir todas las evaluaciones y puntos, ignorando los filtros aplicados en la tabla de resultados.

11.3 Observaciones y salida PDF

  1. Escribir las observaciones que deban aparecer en el informe.
  2. Comprobar que se han generado las evaluaciones, compensaciones o ESQUADRAJE que se desean incluir.
  3. Seleccionar «Imprimir selección».
  4. En el diálogo del navegador, elegir una impresora o «Guardar como PDF».
  5. Revisar el documento final antes de archivarlo o distribuirlo.
Si se selecciona un formato que requiere resultados todavía no calculados, la aplicación mostrará un aviso. Para imprimir tablas de compensación, generarlas primero y seleccionar las tablas que deben incluirse.

13. Buenas prácticas operativas

  • Comprobar que el Quick Report corresponde a la máquina, eje, ensayo y recorrido correctos.
  • Utilizar una tarjeta independiente por evaluación y grupo de puntos.
  • Revisar encabezados, nombres de puntos, coordenadas y unidades antes de calcular.
  • Confirmar punto inicial, punto final, intervalo, ciclos y modo de medición frente al ensayo real.
  • Comprobar la tolerancia y su unidad antes de interpretar PASS o FAIL.
  • Leer todos los avisos y errores mostrados por la aplicación.
  • Revisar los resultados y las tablas de compensación antes de exportarlos.
  • Guardar los CSV, PDF y backups JSON en la ubicación documental definida por la empresa.
  • Antes de cerrar o actualizar la página, exportar o imprimir los resultados que deban conservarse.

14. Alcance y limitaciones conocidas

La aplicación no debe tratarse como almacenamiento permanente de todos los ensayos. La versión analizada indica que el procesamiento de los datos se realiza en el navegador y que los datos no se envían a servidores.
  • Los Quick Reports y las configuraciones principales se procesan en la sesión del navegador; la interfaz analizada no presenta una función general de guardado de proyectos o recuperación de sesiones.
  • Los análisis complementarios sí cuentan con almacenamiento local en el navegador y funciones de exportación e importación de backup JSON.
  • El backup JSON de análisis complementarios no equivale a una copia completa del proyecto ni incluye automáticamente todos los resultados y configuraciones de las demás secciones.
  • Los datos locales pueden no estar disponibles al cambiar de navegador, perfil de usuario o equipo. También pueden perderse si se borran los datos del navegador.
  • La herramienta no sustituye la alineación, Best Fit, adquisición de mediciones ni validación metrológica realizada en el software de origen.

Para una futura versión con historial centralizado, recuperación de formularios y trazabilidad por usuario, sería necesario integrar el guardado de proyectos y resultados con una base de datos y definir permisos de acceso.
